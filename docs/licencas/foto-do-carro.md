# Foto do carro

A foto incluída no app (`app/src/main/res/drawable-nodpi/car_photo.jpg`) é uma cópia reduzida (1200 pixels de largura) de uma imagem do Wikimedia Commons.

- Título: File:Kia Cerato 1.6 SX 2010.jpg
- Página: https://commons.wikimedia.org/wiki/File:Kia_Cerato_1.6_SX_2010.jpg
- Autor: order_242 from Chile
- Licença: CC BY-SA 2.0 (https://creativecommons.org/licenses/by-sa/2.0)
- Alterações: redimensionada para 1200 pixels de largura; nenhuma outra edição.

A licença CC BY-SA exige o crédito acima e que adaptações da imagem usem a mesma licença. O código do app não é derivado da foto. Para usar outra foto, escolha o arquivo em Ajustes (fica só no aparelho) ou troque o arquivo acima e gere o APK de novo.
